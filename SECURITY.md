# Security Policy

## Reporting a Vulnerability

If you find a security issue in LAVNDR120, please report it privately.

- Use "Report a vulnerability" under the Security tab of this repository.
- Please do not publish the details publicly before we have had time to fix it.

We review every report and reply as soon as we can.

## Scope

This repository holds the public website pages. Data and accounts are handled by our backend services; reports about them are welcome through the same channel.
